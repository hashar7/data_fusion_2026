# Идеи для признаков, групп признаков, которые можно добавить в данные

* is_holiday
	Флаг выходного дня по ПК РФ, есть API (https://www.isdayoff.ru/docs/), вроде есть еще библиотека

* prev_n_op_type, prev_n_op_desc(?), prev_n_op_channel, prev_n_op_subchannel(?)
	Тип, описание, канал и подканал n предыдущих операций (предлагаю n=3)

* prev_1_op_timediff
	Время с последней операции
